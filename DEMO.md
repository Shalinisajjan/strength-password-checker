# Demo plan (about 3 minutes)

Use fictional strings only. Do not paste a real account password into a demo, screenshot, recording, or shared machine.

1. Open `index.html` and point out the “PRIVATE BY DESIGN” indicator and educational disclaimer.
2. Enter `cat` to show the short-password feedback.
3. Enter `violet-lantern-river-cobalt-47` to demonstrate how a long fictional passphrase improves the estimate.
4. Enter `aaaaaaaaaaaaaa` to show repeated-character detection.
5. Enter `P@ssw0rd` to show predictable substitution/common-password detection.
6. Toggle Show/Hide, then Clear. Note that no backend is involved and the clear action removes the value from the field.
7. Close with the limitations: a rating is only an estimate; use unique passwords and a password manager.

Optional terminal demonstration: run `node tests.js` and show the fictional cases passing.
